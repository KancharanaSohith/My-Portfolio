# Sohith Kancharana Portfolio

Professional portfolio for Sohith Kancharana, focused on AI systems engineering, agentic AI, voice bots, automation, and full-stack project work.

## Run Locally

```bash
npm install
npm run dev
```

The app runs on Vite at `http://localhost:3000`.

## Build

```bash
npm run build
```

## Asset Notes

- The profile image source is `public/images/sohith-profile.png`.
- Project thumbnails are generated locally in `src/data.ts` so the portfolio does not depend on random placeholder images.
- Generated build output lives in `dist/` and should not be edited directly.
